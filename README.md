# void

Work toward building **the generative field** — a representation in which new
positions, relations, and *dimensions* can emerge, rather than one that maps a
fixed inventory of things.

> A multitude says, "There are many."
> A structured field says, "The many have relations."
> A generative field says: "The relations generate new forms of multiplicity —
> and can transform what it means for something to count as one, many, related,
> or possible."

## The ladder

The text's own summary is the project roadmap. Levels 0–3 are prior art. Level 4
is the name of the project. Level 6 is a constraint on what may be claimed, not
a feature to be shipped.

| Level | | |
|---|---|---|
| 0 | binary | $A$ or $B$ |
| 1 | multitude | $\{A, B, C, \ldots\}$ |
| 2 | structured field | positions plus relations and dimensions |
| 3 | dynamic field | positions and relations changing over time |
| **4** | **generative field** | **new positions, relations, and dimensions emerge** |
| 5 | reflexive field | the field models and modifies its own organization |
| 6 | open becoming | no fixed inventory of future possibilities |

## The invariants

Whatever gets built is accountable to the text's seven closing principles:

1. relations before isolated entities
2. events before static states
3. transformations before classifications
4. individuation before fixed individuals
5. possibility-generation before a fixed possibility space
6. co-evolution before detached observation
7. revisability before final completeness

In keeping with (7), no artifact in this repository asserts completeness.
